# Screenshots Directory

Save your Postman and database screenshots in this folder with the following filenames:

1. `register-success.png` - Successful user registration in Postman
2. `register-failure.png` - Failed registration (e.g. duplicate username or missing fields) in Postman
3. `login-success.png` - Successful login returning JWT in Postman
4. `login-failure.png` - Failed login (invalid username or password) in Postman
5. `database-hash.png` - SQLite database table showing hashed passwords
